# Andy's Emulator

A personal all-in-one emulator for Android: one library for every system, Steam-style, with themes you can customize.

Built on [Lemuroid](https://github.com/Swordfish90/Lemuroid) and [LibretroDroid](https://github.com/Swordfish90/LibretroDroid) by Filippo Scognamiglio, which run libretro emulator cores. Licensed under the GPL-3.0 (see `COPYING`), like the projects it's based on.

## Install

Every push to `main` builds the app on GitHub Actions. Open **Releases**, tap the newest `AndysEmulator.apk` and install it.
